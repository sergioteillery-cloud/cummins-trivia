CUMMINS · TRIVIA POWER ONWARD — VERSION LOCAL PARA WINDOWS
==========================================================

No requiere instalar nada ni tener internet. Necesita Windows 10/11 con Microsoft Edge (o Google Chrome).

1) Descomprime esta carpeta en el totem (por ejemplo C:\Trivia-Cummins). No la dejes dentro del ZIP.
2) Doble clic en "Iniciar-Trivia.bat". Se abre la trivia a pantalla completa.
3) Para que arranque sola al encender el totem: doble clic en "Instalar-Autoinicio.bat"
   (para quitarlo: "Quitar-Autoinicio.bat").

Salir de la pantalla completa:  Alt + F4   (con teclado). Para detener el servidor: "Detener-Trivia.bat".

ADMINISTRACION
- Boton "Admin" arriba a la derecha. PIN por defecto: 1234.
- Preguntas, ajustes (preguntas por ronda, modo con/sin datos, tema) y leads (exportar CSV).
- El CSV se descarga en la carpeta Descargas del totem.

DONDE QUEDAN LOS DATOS
- En la carpeta "datos-navegador" (junto a esta). Si la borras, se pierden leads y ajustes.
- Haz respaldo exportando el CSV antes de cambiar de equipo o reinstalar.

CAMBIAR PREGUNTAS DESDE ARCHIVO
- Edita "app\questions.json" con el Bloc de notas. Cambia tambien "bankVersion" para que el totem use el archivo nuevo.
- Mas simple: usa el panel Admin > Preguntas.

LECTURA EN VOZ ALTA
- El juego trae 3 voces grabadas (Daniela, Claude y Ald): suenan naturales y funcionan sin internet.
  Por defecto usa Daniela; se cambia en Admin > Ajustes > Lectura en voz alta > Voz.
- Las preguntas nuevas o editadas en el admin se leen con la voz del navegador
  (con internet, Edge usa voces "Natural"; sin internet, las basicas de Windows).
- Para escoger otra voz: Admin > Ajustes > Lectura en voz alta > Voz.
- Si no se escucha nada: Configuracion > Hora e idioma > Voz > Agregar voces > Espanol.

TIPOGRAFIA CUMMINS
- El paquete ya incluye la fuente Cummins Innova (carpeta app\fonts). No hace falta instalar nada.

PANTALLA DE REPOSO
- Si nadie toca la pantalla durante 8 minutos, aparece el logo This Ability sobre fondo blanco.
- Al tocar la pantalla se vuelve a la trivia tal como estaba.
- El tiempo se cambia en Admin > Ajustes > Pantalla de reposo (o se apaga).

RECOMENDACIONES PARA EL TOTEM
- Desactiva suspension de pantalla y de equipo (Configuracion > Sistema > Energia).
- Si el totem es tactil, ajusta la orientacion a vertical (Configuracion > Pantalla > Orientacion).
- Si el puerto 8765 esta ocupado, cierra lo que lo use o pide cambiarlo.
